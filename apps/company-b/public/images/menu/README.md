# Menu photos

Drop food photos here named by menu-item slug, e.g.:

    smoky-party-jollof-rice.jpg
    egusi-soup-pounded-yam.jpg
    grilled-salmon-lemon-butter.jpg
    hero.jpg                      (home page hero image)

Slugs come from `content/menu.ts` (the `slug` field of each item). A photo
appears on the site the moment the file exists, no code changes. Until then a
styled fallback renders.

Recommended: JPG, ~1200x900 (4:3) for dishes, ~2000x1200 for hero.jpg.
